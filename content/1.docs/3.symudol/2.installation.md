## Installing Symudol

Symudol runs on Android 7.0 or later. Install it from Zapstore.

1. Install the Zapstore app from [zapstore.dev](https://zapstore.dev), if you do not have it yet.
2. Open the [Symudol page on Zapstore](https://zapstore.dev/apps/io.diogel.symudol), or search for **Symudol** in the Zapstore app.
3. Install Symudol, and allow the install when Android asks.
4. Open **Symudol** from your app launcher.

::note
Symudol is in review for Google Play. This page will link to it once it is available there.
::

## Build from source

This section is for developers who want to run Symudol from its source code.

### What you need

- The Flutter SDK.
- The Android SDK.
- Android Studio, or the command-line Android tools.
- An Android emulator, or an Android phone with USB debugging turned on.

### Steps

1. Clone the repository:

   ```bash
   git clone git@github.com:diogel-io/symudol.git
   cd symudol
   ```

2. Check your tools, and fix anything it reports:

   ```bash
   flutter doctor
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. List your devices, then run the app on the one you want:

   ```bash
   flutter devices
   flutter run
   ```

5. To try a release build on the device, run:

   ```bash
   flutter run --release
   ```

### Build an APK

You can also build an installable file:

```bash
flutter build apk --release
```

Release builds need an Android signing setup before they can be shared safely.

## App ID

Symudol's Android application ID is `io.diogel.symudol`.

Other apps use this ID to reach Symudol. For example, an app sends requests in the background to `content://io.diogel.symudol.SIGN_EVENT`.
