## Installing Diogel Symudol

Symudol is not on Google Play yet, and there is no release download.

To try it now, build it from source and run it on an Android emulator or your own Android phone. This is meant for testers.

Development builds are for testing. Avoid importing a key you rely on.

## Build from source

### What you need

- The Flutter SDK.
- The Android SDK.
- Android Studio, or the command-line Android tools.
- An Android emulator, or an Android phone with USB debugging turned on.

### Steps

1. Clone the repository:

   ```bash
   git clone git@github.com:diogel-io/symudol.git
   cd symudol
   ```

2. Check your tools, and fix anything it reports:

   ```bash
   flutter doctor
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. List your devices, then run the app on the one you want:

   ```bash
   flutter devices
   flutter run
   ```

5. To try a release build on the device, run:

   ```bash
   flutter run --release
   ```

### Build an APK

You can also build an installable file:

```bash
flutter build apk --release
```

Release builds need an Android signing setup before they can be shared safely.

## App ID

Symudol's Android application ID is `io.diogel.symudol`.

Other apps use this ID to reach Symudol. For example, an app sends requests in the background to `content://io.diogel.symudol.SIGN_EVENT`.

In the current development version, the launcher shows the app as **diogel**.

When you first open the app, it asks you to create a 6-digit PIN. Then you add your first identity.
