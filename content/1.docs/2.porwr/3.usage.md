## Porwr: Browser Signing

Once installed, Porwr injects a NIP-07-compatible `window.nostr` provider into websites. When a Nostr web app requests a signature:

1. Porwr shows an approval dialog with the event details
2. You review what's being signed
3. You approve or reject the request
4. If approved, the signature is returned to the web app — your private key never leaves the extension

### Permissions

Porwr supports per-site and per-event-kind permission controls:

- **Always ask** — prompt for every request
- **Always allow** — auto-approve for trusted sites and event kinds
- **Always deny** — automatically reject specific requests

### Vault Lock

The vault auto-locks after a configurable inactivity period. Unlock it with your password to resume signing.

## Bancwr: Team Signing

Bancwr manages signing for teams and organisations:

1. Team members request signatures through the web UI or API
2. Role-based permissions control who can sign what
3. All activity is logged for compliance and audit trails
4. The private key stays inside the bunker — team members never see it
