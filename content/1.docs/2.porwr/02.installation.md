## Installing Porwr

### Chrome

Install from the Chrome Web Store:

<https://chromewebstore.google.com/detail/diogel/inhkmeiabnknligdjngmoocohdonoboa>

### Firefox

Install from Firefox Add-ons:

<https://addons.mozilla.org/en-US/firefox/addon/diogel/>

### Manual installation from GitHub

Manual installation is mostly for testing development builds.

1. Download the latest release ZIP from GitHub.
2. Extract the ZIP file.
3. Open `chrome://extensions` in Chrome or a Chromium-based browser.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted extension folder.

For normal users, the browser store version is recommended.

## First-time setup

When you first open Porwr, you need to create or unlock your vault.

### Create a vault

1. Open the Porwr extension.
2. Choose a strong vault password of at least 8 characters, and type it again to confirm.
3. Create or import a Nostr identity key.
4. Save your recovery information securely.

Your vault password protects the local vault on this browser. It is not a cloud login. Porwr cannot reset or recover it for you, so write it down somewhere safe.

### Create a new Nostr key

Use this if you are new to Nostr or want a fresh identity.

1. Open **Key Management**.
2. Click **Add New Key**.
3. Give the key a recognizable alias.
4. Generate the key.
5. Make a [vault backup](/docs/porwr/keys#vault-backup), or [export the key](/docs/porwr/keys#exporting-a-single-key), and store it securely.

### Import an existing Nostr key

Use this if you already have a Nostr identity.

1. Open **Key Management**.
2. Click **Import Key**.
3. Paste your `nsec...` private key, or an `ncryptsec...` encrypted key, and choose **Import**.
4. For an `ncryptsec`, enter the password it was exported with.
5. Give it an alias.
6. Choose **Save** to add it to the vault.

Only import keys on a device you trust.
