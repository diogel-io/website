## Porwr (Browser Extension)

### Chrome

1. Visit the [Diogel Chrome Web Store page](https://chromewebstore.google.com/detail/diogel/inhkmeiabnknligdjngmoocohdonoboa)
2. Click **Add to Chrome**
3. The extension icon appears in your browser toolbar

### Firefox

1. Visit the [Diogel Firefox Add-ons page](https://addons.mozilla.org/en-US/firefox/addon/diogel/)
2. Click **Add to Firefox**
3. The extension icon appears in your browser toolbar

## Symudol (Android)

Symudol is not released yet. Testers can build it from source: see [Symudol installation](/docs/symudol/installation), and the [Symudol guide](/docs/symudol) for how it works.

## Bancwr (Self-Hosted Bunker)

Bancwr runs on your own server with Podman or Docker Compose, from images published to GitHub Container Registry. See [Bancwr installation](/docs/bancwr/installation) for setup, and the [Bancwr guide](/docs/bancwr) for everything after.
