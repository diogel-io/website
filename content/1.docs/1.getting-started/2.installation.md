## Porwr (Browser Extension)

### Chrome

1. Visit the [Diogel Chrome Web Store page](https://chromewebstore.google.com/detail/diogel/inhkmeiabnknligdjngmoocohdonoboa)
2. Click **Add to Chrome**
3. The extension icon appears in your browser toolbar

### Firefox

1. Visit the [Diogel Firefox Add-ons page](https://addons.mozilla.org/en-US/firefox/addon/diogel/)
2. Click **Add to Firefox**
3. The extension icon appears in your browser toolbar

## Symudol (Android)

Symudol is currently in development. Watch the [GitHub repository](https://github.com/diogel-io/symudol) for updates.

## Bancwr (Self-Hosted Bunker)

Bancwr runs on your own server with Podman or Docker Compose, from images published to GitHub Container Registry. See [Running the Environment](https://github.com/diogel-io/bancwr#running-the-environment) in the Bancwr repository for setup instructions.
